# 피부 일지 (skincare)

바른 것과 피부 상태를 따로 기록해 두고, 날짜로 이어서 살펴보는 스킨케어 일지.
설치형 PWA 정적 사이트라서 `/skincare/` 경로로 바로 열린다.
저장소 루트의 커피노트 앱과는 파일도 데이터도 완전히 분리돼 있다.

## 기록 종류

한 번에 다 적을 필요 없이, 필요한 것만 따로 남긴다.

- **루틴** — 아침/저녁, 단계별로 사용한 화장품·디바이스
- **피부 상태** — 종합 점수(1~5), 트러블 종류와 얼굴 부위, 사진(기록당 2장)
- **생활 요인** — 수면·식사·스트레스·생리주기·기온

## 분석

피부 상태 기록이 10건 이상 쌓이면 통계가 나온다.

- **제품별 영향** — 제품을 쓴 다음 1~3일의 트러블 비율을, 쓰지 않은 날과 비교한다.
  같은 제품 사용일이 3일 이상이고 양쪽 비교군이 각각 3일 이상일 때만 계산한다.
- **생활 요인 영향** — 요인이 있던 날과 그 다음날의 트러블 비율을 나머지 날과 비교한다.

여러 요인이 겹칠 수 있으니 인과가 아니라 "의심 순위"로만 본다. 의학적 진단이 아니다.

## 저장

`localStorage`에 먼저 저장하고, 연결되면 Firestore로 동기화해서 다른 기기에서도 같은 기록을 본다.

| 데이터 | localStorage | Firestore |
| --- | --- | --- |
| 제품 목록 | `skin-products` | `skinLog/products` |
| 기록 | `skin-records` | `skinLog/records` |
| 사진 | `skin-photos:<기록 id>` | `skinLogPhotos/<기록 id>` |

사진은 긴 변 500px·JPEG 0.7로 줄여서 넣고, 기록마다 문서를 따로 둔다.
한 문서에 모으면 Firestore 문서 크기 제한에 걸리기 때문이다.
